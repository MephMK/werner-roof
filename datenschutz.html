Hosting über GitHub Pages

Die Website kann über GitHub Pages gehostet werden. Dabei können technisch erforderliche Verbindungsdaten durch GitHub verarbeitet werden. Vor Veröffentlichung ist zu prüfen, welche datenschutzrechtlichen Hinweise im konkreten Hosting-Setup erforderlich sind.

Server-Logfiles

Beim Aufruf der Website können serverseitig technische Zugriffsdaten verarbeitet werden, etwa IP-Adresse, Datum, Uhrzeit, aufgerufene Datei, Referrer und Browserinformationen, soweit dies durch den Hosting-Anbieter technisch erfolgt.

Kontaktaufnahme

Das auf dieser Website eingebundene Kontaktformular ist im Prototyp statisch. Es werden über das Formular keine Daten an einen Server übertragen. Falls später Kontaktmöglichkeiten ergänzt werden, ist diese Datenschutzerklärung entsprechend anzupassen.

Keine Cookies / kein Tracking

Die Website verwendet im Prototyp keine eingebundenen Trackingdienste, keine Analysewerkzeuge und keine externen Werbedienste.

Rechte betroffener Personen

Betroffene Personen haben nach Maßgabe der anwendbaren Datenschutzgesetze grundsätzlich Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch.

Aktualität und Prüfung

Diese Datenschutzerklärung ist ein Platzhalter und muss vor Veröffentlichung rechtlich geprüft und an die tatsächliche technische Umsetzung angepasst werden.
